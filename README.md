# Research Distortion Map

Черновой React/TypeScript-прототип для Стаси: пользователь выбирает класс, среду и конкретное искажение, а интерфейс показывает, где появляется ошибка, какие этапы она заражает и какие последствия возникают для заказчика, исследователя и респондента.

## Структура

- `src/data/modelData.json` - все содержательные данные: классы, среды, сценарии искажений, последствия и заметки по источникам.
- `src/data/googleSheet.ts` - ссылка на Google-таблицу, из которой дальше можно обновлять данные.
- `src/App.tsx` - основной интерфейс и интерактивная карта.
- `src/model.ts` - небольшие функции для поиска этапов, классов и эффектов.
- `src/styles.css` - визуальная система прототипа.

```bash
node tools/sync-google-sheet.mjs
```

## Как запускать

Когда на машине будет доступен `npm`:

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес, обычно `http://127.0.0.1:5173/`.

## GitHub Pages

Для публикации используется GitHub Actions workflow в `.github/workflows/deploy.yml`.
Локальная сборка запускается командой:

```bash
pnpm run build
```

Сборка для GitHub Pages использует отдельный base-path репозитория:

```bash
pnpm run build:github
```

После push в ветку `main` GitHub должен сам собрать проект и опубликовать папку `dist`.

## Как добавлять данные

Новый сценарий добавляется в массив `distortions` внутри `src/data/modelData.json`.

Минимально нужны:

- `title` - название искажения.
- `roleId` - кто запускает искажение: `customer`, `researcher` или `respondent`.
- `stageId` - где появляется искажение: `task`, `methodology`, `sample`, `collection`, `analysis` или `reporting`.
- `summary` и `mechanism` - короткое объяснение.
- `stageEffects` - последствия по этапам среды.
- `roleEffects` - последствия для трех классов.
- `finalConclusion` - общий вывод.
- `sourceNotes` - научные источники или задачи на их добавление.
